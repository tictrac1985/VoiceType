# مقاطع الاختبار (اختياري)

الطريقة الأسهل للتسجيل هي برنامج **VoiceType Lab** (تبويب "تسجيل الجمل")، وهو يحفظ التسجيلات في `Documents\VoiceType Lab\audio`.

إذا أردت استخدام ملفات جاهزة: ضع كل ملف صوتي وبجواره ملف نصي **بنفس الاسم** فيه الكلام الصحيح (`01.wav` + `01.txt`)، ثم اختر المجلد من تبويب "المقارنة" ← "تغيير مجلد التسجيلات".

- الصيغ: wav, mp3, flac, ogg, m4a, webm. **الأفضل wav أو mp3** (بعض الخدمات لا تقبل m4a).
- الملف النصي بترميز UTF-8، والكلمات الإنجليزية بحروف إنجليزية.
