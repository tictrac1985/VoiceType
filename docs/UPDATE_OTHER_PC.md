# أمر تحديث صدى على الكمبيوتر الثاني (AMD)

انسخ النص اللي تحت الخط وابعته لـ Claude على الكمبيوتر الثاني (DESKTOP-1UECKES).

---

حدّث برنامج «صدى» (VoiceType) على الجهاز ده لآخر نسخة من GitHub (v2.15)، وطبّق نفس الإصلاحات اللي اتعملت على اللاب. اشتغل بالترتيب، ولو أي خطوة فشلت وقّف وقولّي السبب قبل ما تكمل.

**قواعد لازم تلتزم بيها:**
- ممنوع تطبع أو تسجل أو تكتب أي مفتاح API في أي ملف. ممنوع تفتح أو تقرأ `keys.dat`. الطريقة الوحيدة لحفظ مفتاح هي `voicetype-cli.exe keys set <provider> <key>`.
- ممنوع تفعّل أي خدمة مدفوعة (`paid`). ممنوع تنزّل أي حاجة بفلوس.
- ممنوع تمسح أي حاجة في مجلد نماذج Vibe. ممنوع تمسح أي ملف من صدى غير النسخ المكررة في الخطوة 7.
- اعمل نسخة احتياطية من أي ملف إعدادات قبل ما تعدّله.

**0) اتأكد من الجهاز:** اكتب اسم الجهاز والمعالج وكرت الشاشة والرامات. المتوقع: DESKTOP-1UECKES، Ryzen AI 9 HX 370، Radeon 890M (كرت AMD، مفيش NVIDIA، يعني التسريع بـ Vulkan بس، مفيش CUDA)، حوالي 47GB رامات. لو الجهاز مختلف، وقّف وقولّي.

**المجلدات:**
- الكود: `D:\my pro\مساعد الإملاء\VoiceType (الكود المصدري)`. ده مستودع git مربوط بـ `https://github.com/tictrac1985/VoiceType` (خاص).
- البرنامج: `D:\my pro\مساعد الإملاء\VoiceType (البرنامج)`

**1) هات التحديث:** في مجلد الكود شغّل `git status`. لو فيه تعديلات محلية، متمسحهاش، وقّف وقولّي. لو نظيف، شغّل `git pull --ff-only`، وبعدين اكتب آخر 3 سطور من `git log --oneline`. المفروض تلاقي v2.14 و v2.15.

**2) أداة البناء:** `dotnet --list-sdks` لازم يطلع فيه 10.x. لو مش موجود، اسألني الأول قبل ما تسطّب `winget install Microsoft.DotNet.SDK.10`. الأداة دي ببلاش.

**3) الاختبارات:** `dotnet test tests/VoiceType.Tests -c Release`. لازم كل الاختبارات تنجح (202 أو أكتر).

**4) البناء:** اقفل صدى (`Get-Process VoiceType -ErrorAction SilentlyContinue | Stop-Process`)، وبعدين شغّل:
```
dotnet publish src/VoiceType.App -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=none -o "D:\my pro\مساعد الإملاء\VoiceType (البرنامج)"
```

**5) الإعدادات:** اقرأ `data\settings.json`، وده مفيهوش مفاتيح. اتأكد من القيم دي:
- `primary` = `gemini|gemini-3.5-transcribe` (المحرك السريع المتخصص في التفريغ، مش gemini-flash-lite)
- `fallback` = `local|ggml-large-v3-q5_0.bin`
- `useFallback` = true
- `liveTypingBeta` = false

لو أي قيمة مختلفة، اعمل نسخة احتياطية الأول، وبعدين عدّل الحقول دي بس وسيب الباقي زي ما هو.

**6) تسريع كرت الشاشة (AMD / Vulkan):** اتأكد إن الملفين دول موجودين:
- `C:\Windows\System32\vulkan-1.dll` (بييجي مع تعريف AMD)
- `<البرنامج>\runtimes\vulkan\win-x64\ggml-vulkan-whisper.dll`

لو التاني مش موجود، متنزلوش بنفسك. قولّي أسطّبه من جوه البرنامج: الإعدادات ← النماذج المحلية ← تسريع كرت الشاشة. لو الأول مش موجود، قولّي أحدّث تعريف AMD.

**7) مجلد نماذج واحد مع Vibe:** صدى بقى يقرا مجلد نماذج Vibe لوحده.
- لو `%APPDATA%\github.com.thewh1teagle.vibe\app_config.json` مش موجود (يعني Vibe مش متسطّب)، متعملش حاجة في الخطوة دي.
- لو موجود، خد منه قيمة `models_folder`. ولكل ملف `.bin` في `<البرنامج>\data\models`:
  - لو فيه ملف بنفس الاسم في مجلد Vibe، وبصمة SHA-256 متطابقة (`Get-FileHash`)، امسح نسخة صدى بس.
  - لو مفيش ملف بنفس الاسم في مجلد Vibe، انقل الملف من صدى لمجلد Vibe (`Move-Item`).
  - لو الاسم موجود بس البصمة مختلفة، سيب النسختين وقولّي.
- اكتب المساحة اللي اتوفرت.

**8) شغّل صدى:** `Start-Process` على `VoiceType.exe`، واتأكد إنه شغال (`Responding = True`).

**9) التقرير:** اكتبلي:
- رقم آخر commit
- عدد الاختبارات اللي نجحت
- حجم `VoiceType.exe`
- قيم الإعدادات في الخطوة 5
- حالة تسريع كرت الشاشة
- الملفات اللي اتنقلت أو اتمسحت، والمساحة اللي اتوفرت

**ملاحظات بعد التحديث (متعدلش أي كود):**
- النموذج المحلي بقى بيستخدم البحث الأدق (beam search بعرض 5) لما يشتغل على كرت الشاشة، زي Vibe. كرت Radeon 890M كرت مدمج، فبعد كام إملاء بص على `data\logs\dictation.log`. لو أي سطر فيه `local:` واخد أكتر من 20 ثانية، قولّي.
- لو الكتابة في أي برنامج فشلت، هتلاقي في السجل سطر `insert failed: <السبب> app=<البرنامج>`. ابعتهولي.
